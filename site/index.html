GET STARTED

まずは、
自分の端末から。

Bun 1.4.0を用意して、
ローカルでKituneを動かしてみましょう。

READMEで手順を読む ↗
LOCAL DEVELOPMENThttp://localhost:3000

Passkeyを使うため、ホスト名は
localhostを指定します。

  1. 1

    取得して、設定を用意する

    TERMINAL
    git clone https://github.com/glyzinie/Kitune.git
cd Kitune
cp config.example.toml config.toml
cp .env.example .env
bun install --frozen-lockfile
  2. 2

    自分の設定で、起動する

    config.tomlのユーザー・クライアントを編集し、.envにBETTER_AUTH_SECRETとPERSONAL_DEX_CLIENT_SECRETを設定します。各秘密値はopenssl rand -hex 32などで個別に生成してください。

    TERMINAL
    bun run cli check-config
bun run dev
  3. 3

    最初のPasskeyを登録する

    別のターミナルで実行し、表示されたURLをブラウザで開きます。ownerは設定したユーザーIDに置き換えてください。登録URLは15分間、一度だけ有効です。

    ANOTHER TERMINAL
    bun run cli enroll owner
